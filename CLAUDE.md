## Project Overview

Personal portfolio website for Fabricio Agulles (IT Project Manager). Static site deployed to GitHub Pages at `fabriagulles.github.io/portfolio`.

## Development Commands

```bash
npm install       # Install dependencies
npm run dev       # Start Vite dev server
npm run build     # Production build
npm run preview   # Preview production build
npm run build:css # Compile Tailwind → assets/tailwind.css (run after editing classes)
npm run watch:css # Recompile Tailwind on change (during development)
```

Requires `GEMINI_API_KEY` in `.env.local` (exposed as `process.env.API_KEY` and `process.env.GEMINI_API_KEY` via Vite).

### Styling / Tailwind workflow (IMPORTANT)

Tailwind is **NOT** loaded from a CDN. The compiled CSS is **embedded inline**
in `index.html` inside `<style id="tailwind-compiled">`. This is deliberate: the
old `cdn.tailwindcss.com` (Play CDN) compiled CSS in the browser at runtime and
frequently left the page **completely unstyled on mobile** (slow networks, or
in-app browsers like LinkedIn/WhatsApp that block third-party scripts). Embedding
the CSS makes styling load instantly and reliably, with zero external requests.

**After adding/removing any Tailwind class in `index.html` or `index.js`:**
1. `npm run build:css` — regenerates `assets/tailwind.css` (JIT scans both files;
   `tailwind.config.js` `content` must list them so dynamically-added classes in
   `index.js` aren't purged).
2. Replace the contents of the `<style id="tailwind-compiled">` block in
   `index.html` with the new `assets/tailwind.css` output.

`tailwind.config.js`, `src/input.css` and `assets/tailwind.css` are the
reproducible source for that embedded block. Theme colors live in
`tailwind.config.js` (`primary #007bff`, `secondary`, `darkgray`, etc.).

## Architecture

This is a single-page static site with no framework — vanilla HTML/JS with a precompiled Tailwind CSS build:

- **index.html** — The entire site content (single large HTML file with inline styles and Tailwind classes). Written in Spanish. Contains the embedded compiled Tailwind CSS in `<style id="tailwind-compiled">`.
- **index.js** — Client-side interactivity: mobile menu toggle, scroll animations (IntersectionObserver), modal logic for project details. Adds some Tailwind classes dynamically (carousel indicators).
- **tailwind.config.js** — Tailwind config (theme colors, fonts). `content` scans `index.html` + `index.js`.
- **src/input.css** — Tailwind entry (`@tailwind base/components/utilities`).
- **assets/tailwind.css** — Generated by `npm run build:css`; source for the embedded `<style>` block.
- **index.css** — Currently empty; custom component styles live in the `<style>` block in `index.html`.
- **index.tsx** — Placeholder entry point (Apache-2.0 license header only).
- **vite.config.ts** — Vite config with `@` alias to root and Gemini API key injection.

Styling is self-contained (Tailwind embedded). External CDN dependencies remaining: Google Fonts (Poppins) and Font Awesome icons — these degrade gracefully (system font / missing icons) and do not break layout if unavailable.
